# Functional Requirements

## FR-01: Student Registration

The system shall allow an administrator to register a new student.

## FR-02: Student Information

The system shall store the following student information:

* Student ID
* Full Name
* Email Address
* Phone Number
* Program

## FR-03: Student Search

The system shall allow users to search for a student using the Student ID.

## FR-04: View Students

The system shall allow the administrator to view all registered students.

## FR-05: Update Student Information

The system shall allow the administrator to update the information of an existing student.

The administrator shall be able to update:

* Full Name
* Email Address
* Phone Number
* Program

## FR-06: Delete Student

The system shall allow the administrator to delete an existing student record using the Student ID.

## FR-07: Input Validation

The system shall validate that all required student information is provided before registration or updating a student record.

## FR-08: Duplicate Prevention

The system shall prevent registration of two students with the same Student ID.

## FR-09: Student Not Found Handling

The system shall display an appropriate message when a requested student record cannot be found.

## FR-10: Menu Selection

The system shall provide a menu allowing the user to select available operations:

1. Register Student
2. View Students
3. Search Student
4. Update Student
5. Delete Student
6. Exit

## FR-11: Invalid Input Handling

The system shall display an appropriate error message when the user selects an invalid menu option.
