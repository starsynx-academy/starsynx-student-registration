# Non-Functional Requirements

## NFR-01: Usability

The system should provide a simple, clear, and easy-to-use command-line interface.

## NFR-02: Performance

The system should respond to user actions within a reasonable amount of time.

## NFR-03: Reliability

The system should handle invalid input and missing information without crashing.

## NFR-04: Maintainability

The source code should be organized, readable, and easy to modify or extend.

## NFR-05: Data Integrity

The system should maintain accurate student records and prevent duplicate Student IDs.

## NFR-06: Error Handling

The system should provide clear and meaningful error messages when invalid input is entered or a requested student record cannot be found.

## NFR-07: Availability

The system should be available whenever the application is running and ready for authorized use.

## NFR-08: Portability

The system should be able to run on systems that have a compatible Python environment installed.
