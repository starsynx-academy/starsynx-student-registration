# Non-Functional Requirements

## NFR-01: Usability

The system should be simple and easy to use.

## NFR-02: Performance

The system should respond to user actions within a reasonable time.

## NFR-03: Reliability

The system should handle invalid input without crashing.

## NFR-04: Maintainability

The source code should be organized and easy to modify.

## NFR-05: Security

The system should validate user input and prevent unauthorized modification of student records.

## NFR-06: Availability

The system should be available whenever authorized users need to access it.
