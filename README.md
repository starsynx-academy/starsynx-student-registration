# STARSYNX Student Registration System

## Project Overview

The STARSYNX Student Registration System is a mini software project developed as part of a Software Engineering practical.

The system is designed to demonstrate how a software project moves from requirements and design to development and testing.

## Project Objectives

- Register students
- Store student information
- View registered students
- Search for students
- Validate student information
- Demonstrate software testing and debugging

## Target Users

- Students
- System Administrators

## Main Features

- Student Registration
- Student Search
- Student Record Management
- Input Validation
- Error Handling

## Software Engineering Process

This project follows the following development process:

1. Requirements Analysis
2. System Design
3. Development
4. Testing
5. Debugging
6. Documentation
